# Flasqo - AI-Powered API Testing Platform

## 🚀 What is Flasqo?

Flasqo is an **all-in-one API testing platform** that uses AI to automatically generate and execute comprehensive test suites. Built for modern development teams who want to test smarter and ship faster.

> 🖥️ **Desktop app (macOS / Windows / Linux):** Flasqo also ships as a native, fully-local
> desktop app — like Postman, but with the whole automation suite, a manual **Request Builder**,
> and a **built-in offline test library** (no API cost). No login, SQLite storage, works offline.
> See **[DESKTOP.md](DESKTOP.md)** for architecture, how to run it, and how to build installers.

## 🎯 Core Features

### 1. **AI-Powered Test Generation**
- Automatically generates test cases based on your API structure
- Reduces manual test writing by **90%**
- Creates Happy Path, Edge Cases, Negative Tests, and Security Tests

### 2. **Four Testing Types in One Platform**

#### 🧪 Functional Testing

- Custom test case creation

#### ⚡ Smoke Testing
- Quick health checks for critical endpoints
- Perfect for CI/CD pipelines
- Fast deployment validation

#### 📊 Performance Testing
- Load testing (sustained traffic)
- Stress testing (breaking points)
- Spike testing (sudden traffic bursts)
- Endurance testing (long-duration stability)
- Real-time metrics and analytics

#### 💥 Chaos Engineering
- Network latency injection
- Service failure simulation
- Timeout scenarios
- Rate limiting tests
- System resilience validation

## 🛠️ How It Works

```
1. Configure API → Enter endpoint + sample data
2. Set Auth (Optional) → Bearer/API Key/Basic
3. Generate Tests → AI creates 10-100 test cases
4. Review & Customize → Select/Edit/Add custom tests
5. Run Tests → Execute all tests with one click
6. Download Reports → JSON/PDF reports + GitHub integration
```

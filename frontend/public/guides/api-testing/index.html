What is Functional API Testing?

Functional testing validates that your API endpoints work correctly: proper status codes, valid response schemas, correct business logic, and appropriate error handling.

How Flasqo Works

  1. Enter your API base URL
  2. Configure authentication (Bearer, API Key, OAuth)
  3. Add endpoints to test
  4. Click "Generate Tests with AI" - GPT-4 creates comprehensive test cases
  5. Run tests and view detailed results

AI-Generated Test Types

  • Happy Path: Valid inputs return expected outputs
  • Edge Cases: Boundary values, empty data, special characters
  • Negative Tests: Invalid inputs return proper errors
  • Security Tests: SQL injection, XSS, auth bypass attempts
  • Schema Validation: Response structure matches spec

Example

Input: GET /products/:id

AI generates:

  • GET /products/1 → 200 OK
  • GET /products/999999 → 404 Not Found
  • GET /products/abc → 400 Bad Request
  • GET /products/1' OR '1'='1 → 400 (SQL injection blocked)

What is Performance Testing?

Performance testing validates that your API can handle real-world traffic: response times stay fast, no crashes under load, graceful degradation when overloaded.

Test Types in Flasqo

  • Load Testing: Simulate 50-1000 concurrent users, measure response times
  • Stress Testing: Push beyond capacity, find breaking point
  • Spike Testing: Sudden traffic surge (Black Friday, viral post)
  • Endurance Testing: Sustained load over hours, detect memory leaks
  • Scalability Testing: Measure performance as load increases

How to Run in Flasqo

  1. Select Performance Testing from testing types
  2. Enter API endpoint to test
  3. Configure: 100 concurrent users for 5 minutes
  4. Set acceptable threshold: 200ms average response time
  5. Click "Start Load Test"
  6. View real-time metrics: requests/sec, response times, error rate

Metrics Tracked

  • Average response time
  • 95th percentile (p95) response time
  • Requests per second (RPS)
  • Error rate (%)
  • Throughput (MB/s)

When to Run

  • Before major releases
  • After infrastructure changes
  • Before traffic spikes (sales, launches)
  • Weekly to catch performance regressions

API Chaos Testing

What is Chaos Testing?

Chaos testing validates that your API handles failures gracefully by deliberately injecting errors, timeouts, and network issues. Inspired by Netflix's Chaos Monkey.

Chaos Scenarios in Flasqo

  • Timeout Injection: Force 5-30 second delays, test timeout handling
  • Error Simulation: Return 500, 503 errors randomly
  • Network Failures: Dropped connections, partial responses
  • High Latency: Slow responses (1-10 seconds)
  • Random Error Mix: Combine multiple failure types

How to Run in Flasqo

  1. Select Chaos Testing from testing types
  2. Choose chaos scenario (e.g., "Timeout Injection")
  3. Configure: 30% of requests fail with 10s timeout
  4. Add endpoints to test
  5. Run chaos test
  6. Verify: Does your app retry? Show error messages? Fail gracefully?

What Good Resilience Looks Like

  • Automatic retries with exponential backoff
  • Graceful degradation (show cached data)
  • Clear error messages to users
  • Circuit breakers prevent cascade failures
  • Timeouts prevent hanging requests

Real-World Example

Your payment API is slow. Chaos testing reveals:

  • Frontend hangs for 60 seconds (no timeout)
  • Checkout page becomes unresponsive
  • No retry logic when payment gateway is down

Fix: Add 5s timeout, retry 3 times, show "Payment processing, please wait" message.
